# Замысел: переезд витрины на vadimsait.ru в Яндекс Облако

15.11.2026

## Что делаем и зачем

Витрина сайтов Вадима переезжает с зарубежного Vercel
(saiteauto.vercel.app) на собственный домен **vadimsait.ru**,
размещённый в **Яндекс Облаке**. Причина: Vercel из России открывается
через раз (проверено 15.11 - у самого Вадима сайт не открывался ни с
мобильного, ни с домашнего интернета). Клиенты будут теряться на
мёртвой ссылке.

## Цели

- Сайт открывается из России стабильно, по адресу https://vadimsait.ru
- Всё сделанное раньше работает как прежде: главная, демо-сайты,
  страница «Пакеты и цены» с автоценой по городу и анкетой-ТЗ
- Старый адрес на Vercel продолжает работать как запасной
- Код по-прежнему живёт на GitHub, публикация остаётся простой

## Что точно не нужно

- Не нужна оплата картой на сайте, CRM, админка
- Не переделываем дизайн и тексты - только переезд
- Не удаляем Vercel-версию

## Что будет провалом

- Сайт на новом адресе не открывается у части провайдеров
- Автоцена по городу перестала работать или стала показывать неверную
  колонку
- Сломались демо-сайты (они лежат в подпапках)

## Ограничения

- Бюджет: до ~3 000 ₽/год (домен ~300-600 ₽/год + облако ~100-200 ₽/мес)
- Регистрацию домена и облака делает сам Вадим (телефон, карта,
  паспортные данные). Я даю пошаговую инструкцию и делаю всё
  техническое
- HTTPS обязателен (бесплатный сертификат от Яндекса)

## Способы (рассмотрены 15.11)

1. Домен + Cloudflare поверх Vercel - отклонён: Cloudflare тоже режут,
   зависимость от зарубежного сервиса остаётся
2. Домен + обычный российский хостинг - отклонён: дёшево и просто, но
   нет серверных функций, автоцена по городу сломается
3. **Домен + Яндекс Облако - ВЫБРАН Вадимом.** Статика в Object
   Storage (хранилище), гео-функция и будущий бот - в Cloud Functions.
   Всё в одном месте, открывается в РФ

Выбор Яндекса против VK Cloud - моё решение: больше инструкций и
примеров, Вадим не возражал.

## Как устроено технически (моё решение)

- Домен vadimsait.ru регистрируем у reg.ru (или у регистратора Яндекса
  - уточню по цене при регистрации)
- Файлы сайта - в Object Storage (корзина с включённым «веб-сайтом»)
- Домен и бесплатный HTTPS - через Certificate Manager + CDN/хостинг
  Яндекса
- Город посетителя: функция в Cloud Functions определяет по IP через
  гео-сервис (у Яндекса нет готового заголовка города, как у Vercel).
  Та же логика: миллионник - одна колонка цен, остальные - другая;
  не определился - показываем цену миллионника
- Адрес функции: api.vadimsait.ru/geo (поддомен), страница пакетов
  обращается к нему; в файле поменяется одна строка
- Публикация обновлений: git push на GitHub (как сейчас) + заливка
  в хранилище одной командой с компьютера Вадима; автосинхронизацию
  GitHub → Яндекс настроим, если пойдёт легко, иначе команда-заливка

## На усмотрение исполнителя (мои решения)

  Certificate Manager)
- Гео-сервис для определения города (бесплатный, с резервным)
