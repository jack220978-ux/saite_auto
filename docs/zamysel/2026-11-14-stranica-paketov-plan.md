# План: страница «Пакеты и цены» на витрине - 2026-11-14

Цель: новая страница pakety.html с автоопределением цены по городу и
анкетами-ТЗ в мессенджеры.
Замысел: `2026-11-14-stranica-paketov.md` в этой же папке.
Ограничения: CSP connect-src 'self' (гео - только своя функция), главную не
трогаем кроме одного пункта меню, деплой: коммит -> push -> Vercel.

Где скорее всего ошибёмся:
1. Локально заголовков Vercel (x-vercel-ip-city) нет - автоопределение
   проверяется только на живом сайте. Закрываем: fallback-цена миллионника +
   проверка на живом после деплоя.
2. Кириллица в тексте ТЗ может побиться в ссылке мессенджера. Закрываем:
   encodeURIComponent + проверка готовой ссылки.
3. Мобильная вёрстка (у Клода были коммиты про узкие экраны). Закрываем:
   скриншот 390px в headless Chrome.
4. Меню главной - единственная правка живой страницы. Закрываем: скриншот
   главной после правки.

- [ ] Шаг 1. Гео-функция `/api/geo.js`.
  Что делаем: серверная функция читает заголовок города от Vercel, сравнивает
  со списком 16 миллионников, отвечает JSON: колонка цен (регион/миллионник)
  и название города. Без заголовка - отвечает «миллионник» (запасной вариант

  Что меняется: новый файл `api/geo.js`.
