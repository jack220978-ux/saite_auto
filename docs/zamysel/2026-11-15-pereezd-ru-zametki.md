# Переезд витрины на российский адрес - заметки разговора

## Выжимка главного (обновляю по ходу)

Витрина saiteauto.vercel.app из России открывается через раз (провайдеры
режут Vercel и GitHub). Решение: переезд на российское облако со своим
доменом «живые сайты». Вадим выбрал вариант 3 - российское облако
(Яндекс Облако или VK Cloud), где поселятся сайт, гео-функция и будущий
бот. Латинские варианты домена (zhivye-sajty.ru и др.) по DNS скорее
свободны - проверить окончательно при регистрации.

## Журнал

**15.11, после обеда - почему переезжаем.**
Утром сайт у Вадима открывался с мобильного в Тихвине, в 11:45-11:53 уже
не открывается ни с мобильного (другой город), ни с ноутбука (Wi-Fi).
Извне (через внешний сервис) сайт живой и обновлённый. Вывод: блокировка
зарубежных хостингов плавающая, для бизнеса это потеря клиентов.

**15.11 - выбор варианта.**
Предложил 3 варианта: 1) домен + Cloudflare поверх Vercel, 2) домен +
обычный российский хостинг, 3) домен + российское облако (VK/Яндекс).
Вадим: «Вариант 3, домен живые сайты».
Порядок работ: сначала переезд, потом бот (бота привязывать к новому
серверу, чтобы не делать дважды).

**Проверка доменов (мой поиск, 15.11):**
zhivye-sajty.ru, zhivye-saity.ru, zhiviesajty.ru, zhivye-sajty24.ru,
zhivye-sajty-vadim.ru, sajty-zhivye.ru - не резолвятся, скорее свободны.
Окончательно проверяется при регистрации у регистратора.

## Мои решения по умолчанию (сказаны вслух, Вадим может поправить)

- Облако: Яндекс Облако (Object Storage для сайта + Cloud Function для
  гео и бота). Документации и примеров больше, чем у VK.
- Домен: латиница zhivye-sajty.ru (кириллический .рф хуже выглядит
  в ссылках и почте).
- Гео-цена: та же логика (миллионник/регион), но город определяем через
  гео-API из облачной функции - у Яндекса нет готового заголовка города,
  как у Vercel.

**15.11 - домен выбран.**
Вадим выбрал vadimsait.ru (вариант 1 из предложенных).
Аккаунт в Яндексе у него есть.

## Итог переезда (16.11)

Переезд завершён, Вадим подтвердил с телефона: «все ок».
- Прод: https://www.vadimsait.ru (vadimsait.ru перекидывает на www).
- Хранилища Яндекс Облака: vadimsait-ru (тех. адрес), www.vadimsait.ru
  (основной сайт), vadimsait.ru (редирект на www).
- CDN-раздачи: bc8rdhg6jswwfkmkwcxa (www) и bc8rftk4ivved5noqzu6 (apex),
  сертификат fpqj746l2kl2efk3mssv (оба домена, авто-продление Яндексом).
- Важный урок: опция customServerName в CDN так и не применилась
  (NoSuchBucket ~2 часа). Рабочая схема - бакеты с именами доменов
  + опция forwardHostHeader (передавать Host клиента). Сайт-режим S3
  сам находит бакет по имени хоста.
- При ручной заливке файлов в бакет обязательно ACL public-read,
  иначе 403 (однажды поймали на pakety.html и apex.html).
- Гео-цена: pakety.html пробует /api/geo, при сбое - ipwho.is,
  fallback - цена миллионника.
- Vercel-версия (saiteauto.vercel.app) - запасная, не трогаем.
- Следующий этап: бот MAX для заявок (ждём токен от @masterbot).
